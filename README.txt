COMPLIEDGE MULTI-PAGE WEBSITE
================================
Upload the contents of this folder to the ROOT of your GitHub Pages repository.

Main files:
- index.html                 Home page
- logo.png                   Transparent CompliEdge wordmark
- compliedge-ce-mark.png     Closing brand monogram
- sitemap.xml                XML sitemap (all public HTML pages)
- robots.txt                 Allows crawler access and declares sitemap
- CNAME                      Custom domain: compliedge.in
- assets/                    CSS, JavaScript, favicon and service illustrations
- services/                  Individual pages for every listed service
- locations/                 Siliguri, Jalpaiguri, Jaigaon, Odlabari, nearby North Bengal
- blog/                      Blog hub and three educational articles
- careers/                   Careers and vacancy information
- eeat/                      Experience, expertise, accountability and trust page
- legal/                     Privacy, cookies and terms
- faq/                       Frequently asked questions
- pricing/                   2026 indicative fee framework

IMPORTANT BEFORE PUBLISHING:
1. Upload every file and folder, preserving the folder structure.
2. Ensure GitHub Pages publishes from the repository root.
3. The domain compliedge.in must be configured in your repository and DNS.
4. Replace/verify all public business details, vacancy status, legal text and service scope before launch.
5. The enquiry form opens the visitor's email application; it is not a server-side form.
6. No analytics or advertising tracker is installed by default.
